# Workspace Rules - PathPilot

## Collaborative Development Workflow
For every new feature request, bug fix, or code modification:
1. **Restate the Requirement:** Understand the user's requirement and restate it in your own words to confirm understanding.
2. **Technical & Architectural Analysis:** Analyze the technical approach, architectural impact, trade-offs, and dependencies.
3. **Proposed Implementation Plan:** Present the proposed plan in a clear, step-by-step manner.
4. **Obtain Approval first:** Wait for the user's explicit approval. Do NOT write code or modify the project until permission is given.
5. **Agreed Execution:** Only after receiving approval, begin implementation.
6. **Progress Checkpoints:** After completing each major step, provide a brief update and pause for confirmation before proceeding if the next step involves a significant decision.
